# Messier Material Lab

An example project for [Messier Engine](https://github.com/anteroul/messier-engine), a WebGPU game engine and editor
that runs in the browser. It shows off material maps: normal, metallic-roughness, occlusion and emissive textures.

| Scene | What it shows |
| --- | --- |
| **Gallery** | Five pedestals that add the maps one at a time (base color, + normal, + metal/rough, + occlusion, + emissive), in front of a wall of riveted hull plating, under a light that sweeps across them |
| **Orbit** | A plated sphere and a ring of tiled cubes under a low sun that circles them, so every side gets the light in turn |

In Play: `Space` takes every map but the base color off (and puts them back), `N` / `P` load the next and previous
scene.

## Open it

You need the Messier editor in Chrome or Edge (project folders use the File System Access API).

1. Clone this repository.
2. In the editor, **☰ → Open Project…** and pick the cloned folder.
3. Press **▶ Play**, or **Build** to download it as a single web page.

## Where it comes from

The scenes are generated by the engine repository's `src/materialLab/` with `npm run generate:materials`, and every
texture is in `assets/models/material-lab.glb`, generated by `scripts/generate-material-glb.mjs`. Regenerating replaces
the project files (it keeps `.git`, this README and `LICENSE`), so changes made in the editor are overwritten the next
time it's regenerated.
